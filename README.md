# python-task-manager
A simple Python task management application for university
# برنامه مدیریت وظایف (Task Manager)

## معرفی پروژه
این پروژه یک برنامه ساده مدیریت وظایف است که با زبان Python طراحی شده و امکان مدیریت کارهای روزانه را از طریق محیط ترمینال فراهم می‌کند.

## امکانات برنامه
- افزودن وظیفه جدید
- نمایش فهرست وظایف
- حذف وظایف
- مشخص کردن وضعیت انجام‌شده
- ذخیره‌سازی اطلاعات در فایل JSON

## پیش‌نیازها
- نصب Python نسخه 3 به بالا
- نصب Visual Studio Code (اختیاری)

## نحوه اجرا
ابتدا مخزن پروژه را دریافت کنید و وارد پوشه آن شوید.

سپس دستور زیر را در ترمینال اجرا کنید:

```bash
py main.py
```

## ذخیره‌سازی اطلاعات
اطلاعات وظایف در فایل `tasks.json` ذخیره می‌شوند تا پس از بستن و اجرای مجدد برنامه، اطلاعات قبلی باقی بمانند.

## زبان برنامه‌نویسی
Python
